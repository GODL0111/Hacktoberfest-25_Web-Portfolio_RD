# Portfolio (React + Vite)

This is a minimal portfolio scaffold created for you. Replace the placeholder content with your name, bio, projects, images, and links.

Quick start (Windows PowerShell):

```powershell
cd portfolio
npm install
npm run dev
```

This will start Vite's dev server (usually at http://localhost:5173).

What to edit first:
- `src/components/Hero.jsx` — change your name, tagline, bio, and CTA links.
- `src/components/Projects.jsx` — modify the `sampleProjects` array (title, description, tech, link).
- `src/styles/index.css` — tweak colors, fonts, spacing.

This repository has been pre-populated with Rachayita Debnath's details (name, contact, projects, skills, education and simulations). To add a resume PDF, place `resume.pdf` into the `public/` folder and add or update links in `src/components/Contact.jsx` and `Hero.jsx`.

Deployment:
- Build: `npm run build`
- Preview: `npm run preview`

Suggested hosts: Vercel, Netlify, or GitHub Pages (build the site and deploy the `dist` folder).

If you want, provide your personal details (name, bio, projects, images) and I will populate the site for you and add a resume link.
